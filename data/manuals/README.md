# 手册数据

本仓库保留官方来源、车型/年份/地区和 SHA256 清单，不附带厂家完整 PDF。完整手册的版权归原权利人，仓库的 Apache-2.0 许可证不覆盖第三方手册正文。

在仓库根目录按需下载（需要联网，只使用 Python 标准库）：

```bash
python3 scripts/download_manuals.py
python3 scripts/download_manuals.py --verify-only
```

也可以用 `--only Volvo_EC40_2026_UK_en.pdf` 单独下载一份。脚本逐个校验清单指纹；已有文件不重复下载，指纹不符的文件不覆盖、不导入。官网可能替换 PDF；这种情况会明确失败，不会把新版冒充历史语料。可以在车辆知识页面上传自己取得的适用版本，填写正确的车型、年份、地区。

下载完成后启动或重启项目，后端自动提取文本并建立索引。PDF、索引与用户上传保存在本地并被 Git 忽略。没有下载手册仍能运行车控、导航、信息服务、评测报告及可信实验室的精选释义 RAG；工作台完整手册问答需要先下载或上传 PDF，并选择适用手册。

历史索引规模为三份手册、1,182 页、2,794 个片段；这是清单中对应文件的统计，不代表新环境已完成导入。扫描版 PDF 暂不支持 OCR。
